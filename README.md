# WorkCoins UNI

Plataforma universitaria para la gestión de microproyectos y convocatorias académicas entre estudiantes (clientes y freelancers).

## Descripción
Maqueta web desarrollada con **HTML5** y **CSS3** (diseño Mobile First con Flexbox) y JavaScript básico para interacciones de demostración. Diseñada para funcionar de manera local y offline sin requerir frameworks, librerías externas ni servidores backend.

## Estructura del Proyecto
- **`workcoins-web/`**: Núcleo del proyecto web.
  - 20 páginas HTML adaptables para los roles de Cliente y Freelancer.
  - `estilos.css`: Hoja de estilos responsiva única.
  - `acceso.js` y `filtros.js`: Scripts de interacción básica.
  - `imagenes/`: Recursos fotográficos y avatares de perfiles y proyectos.
  - `recursos/`: Archivos descargables de ejemplo (.csv, .txt).
  - `ANALISIS.txt`: Ficha de pantallas, flujos y decisiones de diseño.
  - `PRUEBAS.txt`: Comprobaciones de navegación y accesibilidad.
- **`WorkCoins-escolar.zip`**: Paquete comprimido del proyecto listo para distribución.

## Cómo visualizar el proyecto
1. Clonar este repositorio o descargar y descomprimir el archivo `WorkCoins-escolar.zip`.
2. Abrir el archivo `workcoins-web/index.html` en cualquier navegador web moderno (Chrome, Edge, Firefox, Safari).
3. Seleccionar el rol deseado (*Soy cliente* o *Soy freelancer*), escribir datos de prueba y presionar **Ingresar**.
