WORKCOINS UNI - PROYECTO WEB ESCOLAR

COMO ABRIR
1. Extrae todo el ZIP, conservando sus carpetas.
2. Abre index.html en un navegador actualizado.
3. Elige cliente o freelancer. Escribe un correo de prueba con formato válido
   y una clave ficticia de al menos 4 caracteres; después pulsa Ingresar.
   Ejemplo de correo: estudiante@ejemplo.invalid
No requiere instalar programas, paquetes ni un servidor.

RECORRIDOS
Cliente: panel > publicar oferta o consultar oferta > propuestas recibidas >
evaluar a Sofía > ejemplo de proyecto activo > ejemplo de proyecto finalizado.
Freelancer: panel > explorar ofertas > oferta del portal > formulario de
propuesta > confirmación de ejemplo > proyectos o ganancias.
En la cabecera puedes regresar al panel o cambiar de rol.
En celular, el menú principal aparece en la parte inferior.

ARCHIVOS
20 páginas HTML, estilos.css, acceso.js y filtros.js.
imagenes/: fotografías, avatares y recursos visuales contextuales para perfiles y proyectos.
recursos/: cuatro descargas claramente identificadas como ejemplos.
ANALISIS.txt: pantallas, decisiones, correcciones y alcance de la revisión.
PRUEBAS.txt: comprobaciones realizadas y límites de verificación.

IMPLEMENTACION
HTML5 y CSS3 con Flexbox y consultas de ancho mínimo (Mobile First).
El HTML de cada pantalla se puede editar directamente; no requiere
compilación, frameworks, librerías ni backend.
JavaScript básico: filtro de tres ofertas y elección del destino al ingresar.
El resto utiliza enlaces, formularios, validaciones, details y controles HTML.
Los botones Restablecer recuperan los valores iniciales de su formulario.
El botón Limpiar del acceso vacía sus campos.

LIMITACIONES
Es una maqueta: no autentica, publica, contrata, guarda formularios ni procesa
pagos o reembolsos. Los archivos seleccionados no se suben. Cada pantalla
muestra datos fijos; editar un formulario no modifica las pantallas siguientes.
Los nombres y cantidades de Figma se usan como datos ficticios de demostración.
Las cifras de cabecera indican saldos iniciales: cliente 650, freelancer 85.
Las proyecciones de cada operación se explican por separado.

Se integraron fotografías de perfil agradables y de contexto universitario para
los roles (Carlos, Sofía y candidatos), así como imágenes contextuales locales
de diseño web, prototipos y entregables para sustituir los marcadores provisionales.
Todo funciona de forma 100% local y sin requerir conexión a internet.

Se aplicó una maquetación Mobile First con adaptación para tablet (650 px) y escritorio (1000 px).
Para revisar el análisis completo de las pantallas y las pruebas realizadas, consulta los archivos ANALISIS.txt y PRUEBAS.txt.
